# ТехноПро — учебная система аренды оборудования

## Запуск (Windows)
1. Установите Python 3.11+ с сайта python.org. При установке включите **Add python.exe to PATH**.
2. Распакуйте `TechnoPro.zip` в любую папку.
3. Откройте папку проекта, нажмите на адресную строку Проводника, впишите `cmd`, Enter.
4. В открывшемся окне введите `python app.py` (если не работает, `py app.py`).
5. Откроется окно «ТехноПро». При первом запуске создастся `technopro.db`.

Linux: `python3 app.py`; возможно потребуется пакет `python3-tk`.

## Роли
- `client`: каталог, поиск/фильтры/сортировка, корзина и свои бронирования.
- `manager`: список всех заказов, создание и удаление, просмотр состава.
- `admin`: всё менеджера и изменение даты, статуса и состава заказа.
Пароли по требованиям отсутствуют.

## Структура
- `app.py` — графическое приложение Tkinter.
- `database.sql` — схема SQLite в 3НФ и демонстрационные данные.
- `technopro.db` — база данных (возникает при запуске или поставляется для просмотра).
- `ER_diagram.pdf` — ER-диаграмма таблиц.
- `picture.png` — нейтральная заглушка, если нет фото оборудования.

## Правила
- «Достаточно» при остатке >3, иначе «Мало»; при остатке 0–1 красный фон.
- Скидка 15%, если за предыдущий **полный календарный месяц** не было неотменённых бронирований этой модели.
- Запас списывается при оформлении; возвращается при удалении активного заказа, отмене заказа или удалении позиции.
- Фильтрация, сортировка и поиск применяются одновременно.

## Важно для преподавателя
В задании упомянуты внешние ресурсы (логотип, иконка, фотографии, файлы данных и Git-репозиторий), но эти файлы не приложены. Поэтому используются демонстрационные данные и `picture.png`. Импорт внешних исходных файлов и публикация в выданный Git-репозиторий НЕ выполнялись. Цена, названия и страны в демоданных — примеры. Приложение использует стандартные библиотеки Python, отдельно ставить пакеты через pip не нужно. Для сборки exe (опционально): `pip install pyinstaller`, затем `pyinstaller --onefile --windowed --add-data "database.sql;." app.py` — но пути к данным в exe потребуется адаптировать, поэтому для сдачи предпочтителен запуск из исходников.
